# 验证与能力边界

[返回首页](../README.md) · [评估报告](evaluation.md) · [DeepCAD 训练记录](deepcad-training.md)

## 项目职责

FormaLatent 学习几何统计描述及结构标签，用于编码、描述重建和相似样本检索。几何 VAE 与结构 VAE 独立训练。它不提供从潜向量生成完整 STEP 实体的解码器，也不承担工程审查门禁职责。

| 输出或指标 | 可以说明什么 | 不能据此说明什么 |
| --- | --- | --- |
| 潜向量 | 模型对输入描述的数值编码 | 包含全部 BRep 拓扑、可逆的实体参数 |
| 描述重建 MSE | 指定描述空间的重建误差 | 曲面距离、尺寸精度或实体可制造性 |
| 混合检索分数 | 当前索引中的相对接近程度 | 经过校准的相关性概率 |
| 标签 Brier 误差 | 结构标签输出与目标的误差 | 自然语言理解或装配语义能力 |
| Jaccard 最邻近一致率 | 与标签最近邻代理的一致程度 | 人工相关性标注下的检索准确率 |
| 重载审计通过 | 保存、加载、划分与数值输出的一致性 | 几何生成能力或工程认证 |

## 已记录的独立测试

2026-09-23 的固定 DeepCAD 子集有 415 个训练域样本和 90 个官方 test 样本。训练域内部划出验证集，用于早停和权重选择；官方 test 不参与归一化、词表构建和模型选择。

本次文档整理依据仓库已保存的[结果文件](../benchmarks/deepcad-anysearch-505-results.json)与[审计文件](../benchmarks/deepcad-anysearch-505-audit.json)。审计记录显示 505 个样本均完成编码、解码及重载核对。文档更新没有重新训练该数据集，也没有重新获取原始归档。

结构模型与 SVD 使用相同输入和训练域变换。神经模型的标签 Brier 和 Jaccard 代理较好，数量重建仍显著落后于 SVD。几何模型的对照是训练均值预测，不能将这一对照写成优于所有 CAD 表征方法。

不同样本规模的运行同时改变训练与测试数据，不作为严格匹配的算法增益实验。跨运行变化记录可以保留用于历史观察，但不能单凭百分比推断模型普遍提升。

## 数据与复现

- 内置 STEP 提取器输出 44 维描述；训练和查询的特征名称、顺序与维数必须一致。
- 新模型的归一化只使用训练域。微调保留预训练归一化和完整权重，Adam 状态重新初始化，因此不是断点精确续训。
- 记录级随机划分不能保证零件家族隔离，相关样本可能进入不同子集。
- 仓库不分发原始训练数据和预训练权重；历史实验需另行准备匹配的归档、划分文件和环境。
- 描述去重不能代替完整拓扑同一性检测。原始 CAD 许可、代码许可及衍生文件许可需要分别确认。

原始配置、来源哈希和命令见[DeepCAD 训练记录](deepcad-training.md)。小规模多种子实验、计时条件及性能比较的限制见[评估报告](evaluation.md)。

## 本地可验证流程

[合成示例](getting-started.md)使用 32 条三维向量、固定种子 42、2 维潜空间，验证数据准备、训练、编码、解码和检索。它不测试真实 CAD 表征或未见样本相关性。

已有 pytest 覆盖特征提取、训练、微调、划分、批量运行时、CLI 和结构模型。此次文档整理在 Windows、Python 3.12 的本地环境执行，23 项测试通过；这不是新发布的跨平台性能或准确率基准。

## 与建模及审查项目的关系

[AI-CAD](https://github.com/kkppshuai-svg/ai-cad) 负责建模工作流；FormaLatent 提供学习和检索模块。[USD BRep Review](https://github.com/kkppshuai-svg/usd-brep-review) 提供另一层原生几何与视觉审查能力。

这些职责相互补充，但 FormaLatent 当前 STEP 提取器使用 CadQuery/OpenCascade，没有直接的 NVIDIA USD BRep 特征提取适配器。学习结果不能绕过建模内核和实际几何审查。
