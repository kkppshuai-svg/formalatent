# 评估报告

[返回首页](../README.md)

本报告整理仓库中已保存的小规模实验，记录实现版本 3.0.0 与上游基线的差异。结果不构成大规模泛化评估。

## 实验设计

- 基线：上游 AI-CAD 提交 `52f44be` 中的 `scripts/train_brep_vae.py`。
- 数据：12 个本地几何样本、100 个 DeepCAD 几何样本，均为 44 维描述；原始数据未随仓库发布。
- 配置：随机种子 `11`、`42`、`73`，最大 400 个 epoch，其他参数使用各实现默认值。
- 重建：在相同验证记录上计算原始描述尺度的 MSE。验证集同时用于选择权重，因此不是独立测试集。
- 检索：对原始描述加入标准差为各特征数据标准差 3% 的高斯噪声，再检索原样本身份。索引包含全部样本，结果不等于未见零件的语义检索准确率。
- 计时：训练各计时一次；编码重复 100 轮，对比旧接口逐条调用与缓存运行时的批量调用。计时排除 STEP 特征提取。

基线使用全部记录拟合归一化统计，包含验证信息。新版修复了该问题，故归一化空间中的 loss 不宜直接比较。原始描述 MSE 也可能受大尺度特征主导，不表示每类几何属性均等改善。

## 重建结果

变化率按 `(新版 MSE / 基线 MSE - 1) × 100%` 计算；负值表示误差下降。

### 100 个 DeepCAD 样本

| 随机种子 | 基线 MSE | 新版 MSE | 变化率 |
| --- | --- | --- | --- |
| 11 | 0.071641 | 0.051188 | -28.55% |
| 42 | 0.060434 | 0.051636 | -14.56% |
| 73 | 0.159876 | 0.138983 | -13.07% |

原始记录：[deepcad-results.json](../benchmarks/deepcad-results.json)。

### 12 个本地样本

| 随机种子 | 基线 MSE | 新版 MSE | 变化率 |
| --- | --- | --- | --- |
| 11 | 40.097824 | 48.607317 | +21.22% |
| 42 | 42.394255 | 60.002492 | +41.53% |
| 73 | 42.843433 | 24.435678 | -42.97% |

原始记录：[local-results.json](../benchmarks/local-results.json)。

100 样本实验的三个种子均改善；12 样本实验中两个种子退化、一个改善。不能据此推断新版在所有数据域上更准确。

## 检索与性能

两组实验中，基线与新版的噪声身份检索 Recall@1 均为 `1.0`。该指标已达到上限，现有实验没有证明混合检索的真实准确率增益。

| 数据集 | 批量编码相对加速范围 | 基线训练时间范围 | 新版训练时间范围 |
| --- | --- | --- | --- |
| 100 样本 | 272.9–286.8× | 0.0522–0.1163 s | 0.1317–0.1807 s |
| 12 样本 | 150.4–152.2× | 0.0161–0.0273 s | 0.0186–0.0649 s |

加速范围包含减少权重转换和 Python 调用次数的收益，是调用方式的对比，不是相同批量条件下的内核性能对比。新版训练耗时增加。记录未包含 CPU 型号、依赖版本、重复运行方差或峰值内存，短时间测量的绝对数值不宜用于容量规划。

## 复现

需要自行提供上游基线脚本及同一份几何数据。可从现有 AI-CAD Git 仓库导出基线：

```bash
git -C /path/to/ai-cad show 52f44be:scripts/train_brep_vae.py > /tmp/train_brep_vae_baseline.py
OPENBLAS_NUM_THREADS=1 python benchmarks/evaluate.py \
  --baseline /tmp/train_brep_vae_baseline.py \
  --dataset /path/to/geometry.jsonl \
  --out benchmarks/reproduced-results.json
```

执行前安装 `requirements.txt`。由于原始数据未分发，仅凭本仓库无法逐数值复现已记录结果；替换数据后属于新的实验。重复测量时应保存数据版本、Python/NumPy 版本、硬件信息及线程配置。

## 后续评估建议

正式选型应使用按零件家族隔离的独立测试集，为检索准备人工相关性标签，并在相同批量大小下比较预热后的延迟、吞吐和内存。还应单独评估 STEP 提取开销，以及几何权重对不同零件类别的影响。
